# docs

The repo's own docs, built with Astro Starlight. Run `./build.sh` from the repository root; see the root README for options.

- `src/content/docs/days/` one page per lesson day (file-by-file guide, how to run, expected output, homework)
- `src/content/docs/getting-started.md`, `tools.md`, `homework.md` setup, shared tools, homework index
- Versions are pinned in `package.json` and `package-lock.json`.
