Each day's homework is in two places that say the same thing:

- `homework.md` inside the day's folder (for example `day-05-kubernetes-jobs/homework.md`)
- the **Homework** section at the bottom of the day's page in these docs

Only the assignment text is here. Hints, model answers and grading rubrics are not part of this repository. Do the work in your own repo (`~/heyjob-labs/dayNN/`), not in this clone.
